# GTO Lab · Entrenador de Texas Hold'em

App estática de entrenamiento de NLHE 6-max (100bb). Todos los archivos están en la raíz del repositorio, listos para GitHub Pages.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo (público si usas la cuenta gratuita).
2. Sube **todos** estos archivos a la raíz del repo (no los metas en otra carpeta).
3. En el repo: **Settings → Pages**.
4. Source: **Deploy from a branch**. Branch: `main` (o `master`), folder: `/ (root)`.
5. Guarda. En uno o dos minutos tendrás una URL del tipo `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
6. En el iPhone, ábrela en Safari → botón compartir → **Añadir a pantalla de inicio**.

El progreso se guarda en el navegador (localStorage).

## Abrir en local

Haz doble clic en `index.html`, o en la carpeta ejecuta `python3 -m http.server 8000` y entra en `http://localhost:8000`.
